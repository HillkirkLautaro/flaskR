# ☁️ Flaskr

Microblog ligero y open-source hecho en Html5-CSS3 y JavaScript

---

## 🚀 Funcionalidades

- 📝 Publicaciones tipo microblog (sin algoritmos ni filtros)
- 👤 Registro de usuario con seguridad (reCAPTCHA + hashing de contraseña)
- 📊 Encuestas anónimas con límite de 2 envíos por IP/hora
- 🕵️‍♂️ Seguridad básica: RLS
- 🧩 Open source: podés clonar, modificar y desplegar por tu cuenta, solo cambiar las keys. Se pueden esconder las llaves en un .env, pero no quise
